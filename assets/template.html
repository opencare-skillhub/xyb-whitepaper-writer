编者按

当你翻开这一页，多半是医生刚说"得做个血管通路(PICC/输液港)相关的处置"。那一刻脑子容易一片空白：为什么要做？回家怎么带？会不会很遭罪？这本白皮书就是替你把这些先理清楚。

它不是医学教材，而是一份"过来人经验 + 护理常规"的汇编。复杂一点的主题我们也同步在公众号开了专题。

它不替代任何医疗建议。每个人的病情、身体情况不同，置管/操作时机、拔管条件、方案评估，都请听您的主治。本白皮书的价值，是帮你在见医生前少走弯路、在回家后心里有底。

怎么用这本白皮书：翻开先读致读者信 → 范围与边界 → 30 秒红黄绿急症卡（前三页，1 分钟知道边界与紧急行动）；正文按主题章节顺序读；文末工具包可单独打印：记录表（附录 A）、耗材清单（附录 C）、出院交接单（附录 F）、复诊提问卡（附录 G），以及医护团队审核页（附录 B）。

致读者信　写给刚拿到"血管通路(PICC/输液港)"的你

当你翻开这一页，多半是医生刚说"得做个血管通路(PICC/输液港)相关的处置"。那一刻脑子容易一片空白。这本白皮书就是替你把这些先理清楚。

它是小胰宝社区 · 天工开物基金会基于病友真实照护经验 + 临床护理常规 + 公开诊疗指南整理的科普汇编，不是医学教材，也不替代医嘱。你会读到：术前要准备什么、术后头几天盯什么、每天该看什么、在家怎么照护、紧急情况怎么办，以及一份可以直接打印的工具包（记录表 / 耗材清单 / 出院交接单 / 复诊提问卡）。

你会读到什么 / 不会读到什么：读到“怎么和医护配合、怎么居家观察、怎么安全求助”；读不到“我该不该做、什么时候拔、操作打多少”这类需要结合你病情的个体化决定——这些一定以主治医生和置管团队的意见为准。把这本子当“陪你少走弯路的队友”，而不是“替医生做决定的手册”。

建议顺序：先读前三页（读者信 → 范围与边界 → 急症卡），再把30 秒急症卡贴在冰箱上。遇到拿不准，先翻急症卡看颜色，再按卡上的联络路径找对的人。你不是一个人，小胰宝社区 · 天工开物基金会一直都在。

范围与边界

为了让这本白皮书真正帮到你，先说清它的"责任范围"。一句话：它帮你理解、帮你记录、帮你安全地联系对的人；但它不能替你做医疗决定。

这本白皮书负责这本白皮书不负责
讲清血管通路(PICC/输液港)相关处置是什么、怎么选的大方向替你决定选哪种术式、何时做 / 何时拔
居家观察该看什么（量 / 色 / 皮肤 / 固定 / 体温）判定你的化验单、影像和具体病情
提供可打印工具：记录表、耗材清单、出院交接单、复诊提问卡给出"操作打多少、补多少"的通用处方
列红黄绿急症卡，告诉你何时找谁远程诊断或线上开方
整理社群实证医疗资源（供你与主治沟通参考）承诺疗效、代挂号或转诊

【安全边界】凡是涉及冲管、回输、补液 / 补钾、拔管、换管、出行评估的操作，都必须以你主治 / 置管团队的个体化医嘱为准。本白皮书里所有相关语句都标注了“【安全提示·个体化医嘱】”，看到它就代表：这一步需要先获得团队确认，再动手。

🔴 红 · 立即急诊（按主题填写：如管子完全脱出且压不住 / 大出血；高热寒战；剧烈腹痛；呼吸困难；意识模糊）立刻打 120 或去最近医院急诊，同时联系你的置管医生
🟡 黄 · 当天联系（按主题填写：引流量骤变 / 冲管阻力大疼痛 / 敷料渗液红肿 / 体温 37.5–38.4℃ / 明显浑浊血性）当天联系置管团队 / 专科护士；保留记录本和照片，按指导处理
🟢 绿 · 正常观察每日按量 / 色记录、体温正常；按医嘱维护；皮肤完好、固定稳妥继续居家护理，复诊带齐记录本、交接单与耗材清单

找谁最快：置管 / 引流管问题 → 置管团队或介入科护士站；发热寒战 → 就近急诊 + 告知“带管”；用药 / 方案 → 主治医生。把出院交接单（附录 F）上的 24 小时电话和紧急去处贴在急症卡旁边。
