# 01 · 稳定框架要素（Framework）

本文件定义白皮书"无论主题如何都保持"的结构骨架。新增主题时把内容**映射**到下列章节；可合并/跳过，但必须在目录与正文注明原因。

## 一、文档物理顺序（scaffold 默认生成）

```
封面 (section role=cover, 无页码)
  └ 社区logo + 标题 + 副标题 + "草稿·待医护审核"+版本
编者按
目录
── 前置三页（P0-2，各起新页）──
致读者信
范围与边界（负责/不负责对照表 + 统一安全边界）
30 秒红黄绿急症卡（🔴🟡🟢 三色表）
── 主题章节（标准 11 章，各起新页）──
第一章 基础认知（是什么 / 为什么做 / 怎么选）
第二章 术前：材料准备
第三章 术后头三天（最关键时间窗）
第四章 每日观察（核心指标：量·色·检测·异常）
第五章 长期居家维护（洗澡·渗液·皮肤·固定·拆管）
第六章 营养与支持（盯什么指标）
第七章 在家自己操作（如适用：冲管/回输，授权前置）
第八章 耗材准备
第九章 突发与出行（脱管/应急/飞机动车）
第十章 心理与支持
第十一章 推荐医疗资源（病友实证）
术语快速查询表
── 附录（顺序固定）──
附录 A 记录表（可打印）
附录 B 医护团队审核页
附录 C 耗材清单（附表·可打印）
附录 D 参考资料、致谢与版本说明
附录 E （主题专附，可选：如胆汁回输共识速览）
附录 F 出院交接单（可打印）
附录 G 复诊提问卡（可打印）
附件 （主题完整参考资料，可选）
页脚（分隔线 + 社区卡片 + logo）
```

## 二、各固定页的"职责边界"

| 区块 | 必须包含 | 禁止 |
|---|---|---|
| 致读者信 | 你会读到/不会读到什么；预期管理 | 任何医嘱性判定 |
| 范围与边界 | 负责/不负责对照表；统一安全边界一句话 | 替医生做决定 |
| 急症卡 | 红(120)/黄(当天联系)/绿(正常)三行 + 找谁 | 模糊措辞 |
| 术语表 | 术语/缩写/定义/章节页码 | 冗余大段解释 |
| 附录A 记录表 | 日期·关键指标·异常备注·签名 | — |
| 附录B 审核页 | 模块·审核要点·意见·签名·日期 | — |
| 附录F 交接单 | 导管信息/外露长度/下次维护/24h电话/紧急去处 | — |
| 附录G 提问卡 | 可勾选问题清单 | — |

## 三、主题章节映射规则

- **认知弧不可颠倒**：认知 → 术前 → 术后头三天 → 每日观察 → 居家维护 → 营养 → 自操作 → 耗材 → 突发 → 心理 → 资源。
- 某主题无"在家自操作"（如纯科普），第七章可改为"居家护理误区"或注明"本主题无需居家操作"。
- 对比图放在第一章对比表之后（`{{INSERT_IMAGE_COMPARE}}`）。
- 每个 H2 段落结尾如涉及处置，必须接【安全提示·个体化医嘱】callout。

## 四、版本机制

- 起始 `v0.1`，每次实质修改升 `v0.x`；附录 D 的 D.4 版本说明记录每版变更（参考 PTCD v0.15 写法）。
- 正式发布前统一标记"草稿 · 待双专业审核后发布"。
