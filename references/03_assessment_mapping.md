# 03 · PTCD 白皮书完成度评估 v1 → 技能质量门禁映射

来源：《PTCD白皮书_完成度评估与后续任务_v1.md》。本技能把其中的"优先级"固化为**默认动作**，使新白皮书一出生即达到 PTCD v0.15 的完成度。

## 评估优先级总览

| 优先级 | 含义 | 在技能中的处理 |
|---|---|---|
| **P0（阻断发布）** | 不做不能发 | 默认补齐，scaffold 直接产出 |
| **P1（发布质量）** | 发布前必做 | 标"待审核/待核验"，不自动编造 |
| **P2（打磨）** | 提升体验 | 默认执行（分页、清理占位、版本） |

## P0 明细 → 技能动作

### P0-1 标题统一
- 评估：封面/正文/页脚混用"经验集/白皮书"，命名不统一。
- 技能：scaffold 统一为"《<主题>白皮书》"；若主题有通俗名≠专业名（如 PTCD↔PTBD），在封面副行注明"为通俗用语，专业称 XX"。

### P0-2 前置三页（读者信 / 范围边界 / 急症卡）
- 评估：缺读者视角前置，边界不清、无紧急分诊。
- 技能：**scaffold 直接生成三页**，模板内容可编辑；急症卡三色表结构锁定。

### P0-3 安全校准
- 评估：医学建议未标定个体化边界，有误导风险。
- 技能：凡涉及 **冲管/回输/补液补钾/拔管换管/出行评估** 的语句，强制接【安全提示·个体化医嘱】callout；"范围与边界"设统一安全边界一句话。

### P0-4 决策章节改写（沟通卡 + 共同决策）
- 评估：决策内容应呈现"沟通要点"而非"替患者决定"。
- 技能：第七章/决策类章节模板以"沟通卡 + 需与团队确认的问题"形式呈现（参考 PTCD 术前谈话表）。

### P0-5 内容合并（同源不重复）
- 评估：胆汁回输在正文/附录/附件重复。
- 技能：同源内容只录一处——正文讲"能不能讨论"，附录 E 放"要点速览"，文末附件放"完整摘录"，并注明三者同源不重复。

### P0-6 技术细节外移
- 评估：冲管等技术细节过细，宜外移为认证附件。
- 技能：居家自操作章只写"授权前置 + 什么情况停手找团队"，详细步骤留给医护授权材料（标注"以团队提供为准"）。

### P0-7 工具包（出院交接单 / 复诊提问卡）
- 评估：缺可打印实用工具。
- 技能：**scaffold 直接产出附录 F 出院交接单 + 附录 G 复诊提问卡**，与记录表/耗材清单成"可打印五件套"。

## P1 明细 → 技能动作（标待办，不自动编造）

- **图像授权核验**：嵌入任何病友实拍/示意图，须注明脱敏授权；scaffold 在图片 caption 留"（脱敏授权）"占位。
- **资源出处核验**：附录 D 每条参考须有真实出处（期刊/机构/年份/DOI 优先）；agent 填充时不得虚构，缺失标"待补"。
- **试读测试**：交付前建议找 1–2 名新病友试读；技能在附录 B 审核页预留"试读反馈"行。

## P2 明细 → 技能动作（默认执行）

- **占位清理**：删除"图片位置（待补）"类占位，改为"定稿时由医护授权/补入"中性表述；finalize 校验 0 个 `INSERT_IMAGE` 残留。
- **分页优化**：每 H1 分页起页（封面除外）。
- **版本管理**：v0.x 草稿迭代，附录 D 记变更。

## 发布门槛（技能不自行跨越）

当前产物一律标记"草稿 · 待双专业审核后发布"。P0-4/5/6 的内容改写、P1 的核验与试读、以及"公开版/审核版分离"，属于发布流程，需人工/医护推进 M1–M4 里程碑。
